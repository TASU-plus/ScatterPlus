ScatterPlus - 散布図設定ツール ver.3.1.0
================================================================================

この度は「ScatterPlus」をご利用いただきありがとうございます。
本ツールは、Excelの散布図作成および書式設定を効率化するためのアドインです。

--------------------------------------------------------------------------------
1. インストール方法
--------------------------------------------------------------------------------
同梱の「install.vbs」を使用することでセットアップが可能です。

  1) 実行中のExcelをすべて保存して閉じます。
  2) 「install.vbs」をダブルクリックします。
  3) 「セットアップが正常に完了しました」と表示されたら完了です。
  4) Excelを起動すると、リボンに「ScatterPlus」タブが表示されます。

※手動でインストールする場合は、アドインフォルダにScatterPlus.xlamをコピーし、
  Excelの「ファイル」＞「オプション」＞「アドイン」＞「設定」から、

  「ScatterPlus - 散布図設定ツール」にチェックを入れて、有効にしてください。

　アドインフォルダ：%AppData%\Microsoft\AddIns

--------------------------------------------------------------------------------
2. アンインストール方法
--------------------------------------------------------------------------------
  1) 実行中のExcelをすべて保存して閉じます。
  2) 同梱の「uninstall.vbs」をダブルクリックしてください。
  3) アドインの登録が解除され、ファイルが削除されます。

--------------------------------------------------------------------------------
3. 主な機能 (「ScatterPlus」タブ内の機能)
--------------------------------------------------------------------------------
・作成　　: 選択範囲のデータから、散布図を新規作成します。
・自動整形: 既存グラフのプロットエリアやマーカーを所定の書式に整えます。
・詳細設定: 各種フォーマットの微調整や動作設定を行います。

--------------------------------------------------------------------------------
4. 動作環境
--------------------------------------------------------------------------------
以下の環境にて動作検証を行っています。
・OS: Windows 11
・Excel: Excel 2024 (VBA環境が動作すること)

※以下の環境については動作可能と推測されますが、未検証です。
  OS: Windows 10
  Excel: Microsoft Office 365 / Excel 2021等
※上記以外のバージョンでの動作についてはサポート外となります。
